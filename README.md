## Morphine and Marinol Example Study
### REDCap Clinical Data Management Project | Academic Project

PID: 67123 | Status: Development | Data Collection: Longitudinal
Completed: 2024 | Context: University Coursework/Training

## Project Overview

This was an academic project completed during my studies, where I designed
and configured a longitudinal clinical study database in REDCap (Research
Electronic Data Capture), a secure web application widely used in clinical
and translational research.

The study focused on pain response outcomes associated with Morphine and
Marinol (dronabinol) drug combinations, using structured longitudinal data
collection with defined events and validated instruments.

## Data Collection Instruments

3 instruments, 46 fields total

1. Patient Demographics And Baseline Data — 17 fields
2. PROMIS - Anxiety Data — 7 fields
3. Thermal Data — 22 fields

## Instrument Details

### Patient Demographics And Baseline Data
- first_name, last_name, baseline_visit_date
- Confounding variables: gender, hair_colour, dominant_hand, weight_kg
- Identifier fields tagged for data privacy compliance

### PROMIS - Anxiety Data
- Validated Patient-Reported Outcomes Measurement Information System scale
- 7 standardized anxiety measurement fields

### Thermal Data
- date_of_visit, drug_combination
- Round 1 Sensory Pain Measurements:
  thermal_combination_1, sensory_pain_measurement_1/2/3
- Round 2 Affective Pain Measurements

## REDCap Features Used

- Online Designer (instrument and field creation)
- Longitudinal data collection with defined events
- Survey configuration
- Identifier tagging (Check For Identifiers)
- PROMIS Instrument Library integration
- Field types: text, dropdown, date (D-M-Y), section headers
